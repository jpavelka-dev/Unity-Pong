# Unity Pong

Jednoduchá 2D hra Pong vytvořená v Unity a C# jako jeden z mých prvních výukových Unity projektů.

## Funkce

- ovládání hráčova pádla
- počítačem řízený protivník
- fyzika a odrážení míčku
- počítání skóre
- detekce gólů
- hlavní menu
- herní UI a jednoduché vizuální efekty

## Použité technologie

- Unity
- C#
- Rigidbody2D
- Unity UI

## Spuštění projektu

1. Naklonujte repozitář.
2. Otevřete Unity Hub.
3. Zvolte `Add project from disk`.
4. Vyberte složku projektu.
5. Otevřete hlavní scénu v `Assets`.

## Poznámka

Projekt vznikl jako součást mého studia Unity a programování v C#.
